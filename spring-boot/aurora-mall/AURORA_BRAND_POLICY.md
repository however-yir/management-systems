# Aurora Brand Policy

This document defines branding rules for the Aurora Mall fork.

## 1. Scope

This policy applies to:

- repository name and description
- logos, marks, favicon, and visual identity assets
- screenshots and demo videos published with this project

## 2. Relationship to Open-Source License

- Code licensing remains governed by `LICENSE` (upstream GPL terms remain in effect).
- This file does not add extra restrictions to source code usage rights under GPL.
- It only clarifies naming and branding guidance for this fork identity.

## 3. Naming Guidance

- Preferred project name: `Aurora Mall`
- Maven coordinates: `io.howeveryir:aurora-mall`
- Java base package: `io.howeveryir.auroramall`
- Docker service prefixes: `aurora-*`

## 4. Brand Asset Guidance

- Preferred logo asset: `src/main/resources/static/mall/image/aurora-mark.svg`
- Preferred admin logo asset: `src/main/resources/static/admin/dist/img/aurora-mark.svg`
- Preferred favicon asset: `src/main/resources/static/aurora-favicon.svg`
- Deprecated legacy logo files should not be referenced by templates or styles.

## 5. Distribution Notes

- Keep `NOTICE.md` and `THIRD_PARTY.md` when redistributing.
- Keep attribution to upstream project history where legally required.
- When publishing screenshots, avoid legacy names and old logos.
