Aurora Mall 概览

Aurora Mall 是一个面向二次开发的单体电商基座，覆盖商城首页、商品分类、搜索、购物车、订单流转和后台运营管理。 当前版本已经完成第一轮品牌迁移与配置外置，适合作为个人作品集、课程重构项目或业务原型继续演进。

  • 统一了 Maven 坐标和 Java 包命名空间
  • 数据库与上传目录已经支持环境变量配置
  • 补充了 Dockerfile、Compose 和示例环境变量
  • 文档、模板标题和后台品牌入口已切换为 Aurora Mall
